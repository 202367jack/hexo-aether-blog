# 模板

复制这里的东西去用，别直接改这里的文件（改坏了下次复制出来就是坏的）。

| 要写什么 | 复制哪个 | 粘到哪里 | 之后要改名吗 |
| --- | --- | --- | --- |
| 随笔 | `随笔.md` | `source\_posts\` | 要，改成 `日期-英文短名.md`，再建同名文件夹放图 |
| 笔记 | `笔记.md` | `source\_posts\` | 同上 |
| 影视评价 | `影视评价\` 整个文件夹 | `source\media\` | 要，改成英文短名 |
| 项目 | `项目\` 整个文件夹 | `source\projects\` | 要，改成英文短名 |

详细步骤（全鼠标）见根目录的 **`写作指南.md`**。

几个硬规则：

- 文件名 / 文件夹名只能用**英文小写、数字、短横线**，它决定网址；
- 每个模板开头的 `---` 之间的部分是字段，别把两条 `---` 删了；
- 图片文件夹必须和 `.md` **同名**（随笔/笔记才有这一步）。
